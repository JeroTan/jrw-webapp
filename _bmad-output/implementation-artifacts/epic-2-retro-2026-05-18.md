## Key Insights

1. **Agent sandbox timeouts are hardware constraints, not code defects** — When `npm run build-test` times out in the agent environment, it should be flagged for MR. JRW's verification, not recorded as a story blocker.
2. **Targeted tests during dev, full suite by MR. JRW** — Efficient division of labor. Agent runs only changed-file tests during implementation; MR. JRW runs the full suite on their faster machine and reports results.
3. **`.env` is the source of truth** — Seed credentials should never be rejected as "placeholders." If it's in `.env`, it's real.
4. **Model tiering is the right strategy** — The review tier (GPT 5.4) consistently caught architecturally significant issues that the dev tier (GPT 5.3) missed. The pre-review self-check from Epic 1's retro isn't worth the effort.
5. **Smart seed auto-detection** — Seed script should auto-detect: no-op (same email), dethrone (different email), create (no owner). No manual confirmation gates needed for development.

## Post-Retro Fixes Applied During Retrospective

### Fix 1: Super Admin Seed Credential Validation
- **Problem**: `npm run seed:super-admin` rejected `.env` credentials with "Super Admin seed credentials are missing or invalid."
- **Root cause**: `src/domain/auth/super-admin-seed.ts` contained `hasPlaceholderValue()` that hardcoded `super-admin@example.com` as a rejected placeholder.
- **Fix**: Removed `hasPlaceholderValue()` entirely. `.env` is now treated as the source of truth.

### Fix 2: Smart Seed Dethrone Logic
- **Problem**: No way to replace an existing owner with a new email without manual confirmation gates.
- **Fix**: Added three auto-detected modes:
  - `no-op` — seed email matches current owner, no changes needed
  - `dethrone-and-create-owner` — seed email differs, demote old owner, create new SUPER_ADMIN
  - `create-owner` — no owner exists, create new SUPER_ADMIN
- Uses `buildSeededOwnerCountSql()` to detect if the seed email already owns the account.

### Fix 3: `replace-owner-credentials` → `no-op`
- **Refinement**: When seed email matches current owner, the script now exits immediately with "no changes needed" instead of running an unnecessary UPDATE.
